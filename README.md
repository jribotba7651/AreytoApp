# Areyto

> Areyto is the writing IDE for serious authors. The name comes from the Taíno ceremony where the people gathered to sing, dance, and tell their stories — the original act of narration. Built by Jíbaro en la Luna LLC.

A desktop app (Tauri + React) for chapter-based book writing with embedded AI CLIs and automatic git versioning.

## Dev

```bash
pnpm tauri dev
```

## Test

```bash
pnpm test
```

## Build

```bash
pnpm tauri build
```
